# 安全与数据规范

## 数据

- 只允许提交虚构或完成脱敏处理的演示数据。
- 不提交真实姓名、联系方式、证件号、合同内容、供应商敏感信息或生产数据库导出。
- 演示数据必须能够通过成果自带脚本重建。

## 凭据

- `.env`、访问令牌、密码、私钥和生产连接字符串不得进入 Git。
- 仅提交 `.env.example`，变量值使用安全的本地默认值或占位符。
- 外部服务默认使用 Mock；确需访问外部环境时，由使用者在本地提供凭据。

## 发布

- 默认仅在本地运行和评审。
- 未明确确认仓库可见性、页面可见性和数据敏感性前，不启用 GitHub Pages 或其他公开发布。
- 截图、录屏和导出包同样执行数据脱敏要求。

## 依赖

- 锁定应用依赖和容器镜像版本。
- 禁止使用 `latest` 镜像标签。
- 定期验证 `approved` 和 `archived` Demo 是否仍可按照 README 启动。
