# 1. 产品概述

## 1.1 建设目标

本模块用于在海上风电建设管理平台内集中维护海上换流站下部基础的建造进度，形成覆盖备料、钢管桩、主体构件、附属构件和总装任务的统一人工台账。

正式产品数据由用户通过页面人工维护，不提供外部系统自动同步能力。

系统应实现以下目标：

- 通过统一入口维护五类进度对象的计划、实际、进度、责任人和备注信息。
- 通过总览实时汇总项目整体完成率、专项进度和近期更新情况。
- 统一新增、查看、编辑、删除、查询、分页和表单校验交互。
- 通过人员字典、自动状态、连续序号和日期联动提高人工维护的数据一致性。
- 保持与现有海上风电建设管理平台的视觉框架和 RBAC 鉴权体系一致。

## 1.2 目标用户

目标用户为已通过现有平台 RBAC 鉴权、具备本模块访问或操作权限的平台用户。本模块不新建业务角色、不定义字段级权限，也不改变平台已有的认证、授权和数据范围控制方式。

## 1.3 核心使用场景

1. 用户进入总览，查看项目整体完成率、专项进度和最近 7 天更新对象。
2. 用户切换至任一业务页，通过条件组合查询目标对象。
3. 用户新增备料、钢管桩、构件或总装任务，并填写计划与实际信息。
4. 用户查看或编辑既有对象，更新进度、实际日期、责任人和备注。
5. 用户确认后软删除（逻辑删除）错误或不再需要的对象。
6. 系统在保存或删除后立即刷新列表、连续序号和总览指标。

# 2. 信息架构与全局框架

## 2.1 页面框架

页面沿用现有平台桌面端框架，由左侧平台导航、顶部信息栏、一级页签和主内容区组成。

- 左侧平台导航展示平台名称、平台级占位菜单和当前模块入口。占位菜单依次为：数字门户、项目中心、基础信息、组织架构、人员管理、设备管理、船舶管理、风场气象、进度管理、安全管理。
- “海上站下部基础建造进度管理”位于左侧导航最后并保持选中；菜单文字每行最多显示 9 个汉字，超出后自动换行。选中项字重与其他菜单一致，通过背景色和文字颜色区分状态。
- 顶部信息栏展示菜单入口、当前模块名称、在线状态和当前用户信息。
- 一级页签固定为：总览、备料进度、钢管桩制作进度、主体构件制作进度、附属构件制作进度、总装进度。
- 主内容区根据当前页签展示总览卡片或业务台账。

上述占位菜单在 Demo 中仅用于还原平台框架，不提供页面跳转或业务功能。正式产品中的菜单折叠、平台菜单功能、在线状态和用户头像等平台级能力由现有平台统一提供，本模块不单独定义。

五类业务页采用相同结构：

1. 第一行：查询条件、查询按钮、重置按钮。
2. 第二行：当前页面标题、新增按钮。
3. 中部：可横向滚动的数据表格，固定序号列及名称/编号列。
4. 底部：总条数、每页条数和上一页/下一页。
5. 新增、查看、编辑：720px 居中弹窗，当前高度基线为 716px；内容超出可用高度时仅弹窗内容区滚动。

# 3. 核心业务流程

## 3.1 查询流程

1. 用户进入业务页，系统展示默认列表和默认分页状态。
2. 用户填写一个或多个查询条件。
3. 用户点击“查询”，系统组合应用全部条件，并返回第 1 页结果。
4. 无符合条件的数据时，表格展示“暂无符合条件的数据”。
5. 用户点击“重置”，系统清空当前页全部条件、返回第 1 页并恢复完整列表。

## 3.2 新增流程

1. 用户点击“新增”。
2. 系统打开对应对象的新增弹窗；序号、状态和最后更新时间只读。
3. 用户填写字段，状态随进度或到货量实时联动。
4. 用户点击“保存”，系统执行必填、格式、范围和日期关系校验。
5. 校验失败时，弹窗保持打开，并在对应字段下方显示错误信息。
6. 校验通过后，系统保存对象、写入最后更新时间、关闭弹窗并刷新列表和总览。

## 3.3 查看与编辑流程

- 点击名称/编号或“查看”，打开只读弹窗；全部业务控件禁用，底部仅显示“关闭”。
- 点击“编辑”，打开可编辑弹窗；保存流程与新增一致。
- 编辑弹窗打开后，系统记录初始值。用户修改任一可编辑字段后，弹窗进入“有未保存修改”状态。

## 3.4 删除流程

1. 用户点击目标行“删除”。
2. 系统展示确认提示，明确对象类型和对象名称/编号。
3. 用户取消时不改变任何数据。
4. 用户确认后，系统将该对象标记为已删除，并从业务列表、查询结果和统计指标中排除。
5. 删除完成后刷新列表、连续序号、总条数、分页和总览指标。

## 3.5 未保存退出流程

- 新增或编辑弹窗未发生修改时，点击取消、关闭图标、遮罩或按 Esc 直接关闭。
- 已发生修改时，上述退出方式均先提示“当前内容尚未保存，确认放弃修改吗？”。
- 用户选择继续编辑时，弹窗保持打开且数据不丢失。
- 用户选择放弃修改时，关闭弹窗并丢弃本次未保存内容。
- 保存成功后的自动关闭不触发该提示。

# 4. 页面功能需求

## 4.1 总览

### 4.1.1 顶部指标

总览顶部单行展示 6 个指标卡：

| 指标 | 计算口径 | 初始数据展示值 |
|---|---|---:|
| 项目整体完成率 | 备料、钢管桩、主体构件、附属构件、总装五类指标等权平均 | 79% |
| 钢管桩整体进度 | 全部钢管桩制作进度算术平均 | 66% |
| 主体构件整体进度 | 全部主体构件制作进度算术平均 | 99% |
| 附属构件整体进度 | 全部附属构件制作进度算术平均 | 75% |
| 总装进度 | 已完成总装任务数 ÷ 总装任务总数 | 57% |
| 最近更新数据 | 最近 7 个自然日内发生更新的去重对象数 | 11 |

备料指标参与项目整体完成率计算，但不单独占用指标卡；主体构件指标独立展示，并继续参与项目整体完成率计算。

### 4.1.2 最近更新数据

- 统计窗口包含当天及向前 6 个自然日，以平台业务时区的当天 00:00:00—23:59:59 为边界。
- 同一对象在窗口内更新多次只计 1 个对象，并仅展示其最后一次更新时间。
- 不同业务类型下即使名称相同，也按不同对象统计。
- 列表按最后更新时间倒序展示对象名称、业务类型、责任人和更新时间。
- 无符合条件的对象时展示“最近7天暂无更新数据”。

### 4.1.3 钢管桩制作进度摘要

- 按当前钢管桩列表顺序展示所有钢管桩编号、进度条和进度百分比。
- 点击“查看详情”进入钢管桩制作进度页。

### 4.1.4 附属构件制作进度摘要

- 按当前附属构件列表顺序展示所有附属构件名称、进度条和进度百分比。
- 指标卡继续展示附属构件平均进度，不替换为浮筒单项进度。
- 点击“查看详情”进入附属构件制作进度页。

### 4.1.5 总装近况

- 优先展示进度小于 100% 的未完成任务，按当前总装任务列表顺序取前 8 条。
- 若全部任务均已完成，则按当前列表顺序展示前 8 条任务。
- 每条展示连续序号、任务名称、状态和进度。
- 点击“查看详情”进入总装进度页。

## 4.2 备料进度

### 4.2.1 查询条件

| 条件 | 控件 | 匹配规则 |
|---|---|---|
| 材料名称 | 文本框 | 包含匹配，不区分英文大小写 |
| 规格 | 文本框 | 包含匹配，不区分英文大小写 |
| 状态 | 下拉框 | 未开始、进行中、已完成，精确匹配 |
| 责任人 | 人员字典下拉框 | 精确匹配 |

### 4.2.2 列表字段

| 顺序 | 字段 | 展示要求 |
|---:|---|---|
| 1 | 序号 | 按当前查询结果连续生成 |
| 2 | 材料名称 | 可点击查看 |
| 3 | 规格 | 文本 |
| 4 | 计划量(t) | 保留 2 位小数 |
| 5 | 已到货量(t) | 保留 2 位小数 |
| 6 | 备料进度 | 进度条与整数百分比 |
| 7 | 计划开始到货 | 日期 |
| 8 | 计划完成到货 | 日期 |
| 9 | 实际首日到货 | 日期，空值显示“—” |
| 10 | 实际末日到货 | 日期，空值显示“—” |
| 11 | 状态 | 状态标签 |
| 12 | 责任人 | 人员姓名 |
| 13 | 备注 | 空值显示“—” |
| 14 | 最后更新 | 时间 |
| 15 | 操作 | 查看、编辑、删除 |

### 4.2.3 表单字段

| 字段 | 必填 | 编辑方式 | 规则 |
|---|:---:|---|---|
| 序号 | — | 只读 | 保存后按列表顺序生成 |
| 材料名称 | 是 | 文本 | 不得为空 |
| 规格 | 否 | 文本 | 可空 |
| 计划量（吨） | 是 | 数字 | 大于 0，最多支持 3 位小数 |
| 已到货量（吨） | 否 | 数字 | 默认 0，最多支持 3 位小数，不得小于 0 或大于计划量 |
| 状态 | — | 只读 | 根据备料进度自动生成 |
| 责任人 | 是 | 人员字典 | 必须选择有效人员 |
| 计划开始到货 | 是 | 日期 | 不得晚于计划完成到货 |
| 计划完成到货 | 是 | 日期 | 不得早于计划开始到货 |
| 实际首日到货 | 否 | 日期 | 实际末日存在时必填 |
| 实际末日到货 | 否 | 日期 | 不得早于实际首日到货；填写后自动将已到货量设为计划量 |
| 最后更新 | — | 只读 | 保存时由系统写入 |
| 备注 | 否 | 多行文本 | 可空 |

备料进度由系统计算，用户不直接录入。已到货量等于计划量时进度为 100%；未全部到货时，四舍五入结果最高为 99%。数量按最多 3 位小数存储和输入，列表统一四舍五入显示 2 位小数。

# 6. 业务规则与计算口径

## 6.1 状态规则

| 进度 | 状态 |
|---:|---|
| 0% | 未开始 |
| 1%—99% | 进行中 |
| 100% | 已完成 |

状态不可手工修改，进度或已到货量变化时实时刷新。

## 6.2 备料进度

设计划量为 `planQty`、已到货量为 `receivedQty`：

- `planQty <= 0` 时不允许保存。
- `receivedQty = 0` 时，备料进度为 0%。
- `0 < receivedQty < planQty` 时，备料进度为 `min(99, round(receivedQty / planQty × 100))`。
- `receivedQty = planQty` 时，备料进度为 100%。
- `receivedQty > planQty` 时不允许保存。

## 6.3 分类指标

- 备料指标 `M`：所有备料对象进度的算术平均，四舍五入为整数。
- 钢管桩指标 `P`：所有钢管桩制作进度的算术平均，四舍五入为整数。
- 主体构件指标 `B`：所有主体构件制作进度的算术平均，四舍五入为整数。
- 附属构件指标 `S`：所有附属构件制作进度的算术平均，四舍五入为整数。
- 总装指标 `L`：`已完成任务数 ÷ 总任务数 × 100`，四舍五入为整数；进度为 100% 的任务计为已完成。
- 某一分类无任何对象时，该分类指标记为 0，仍参与项目整体完成率计算。

## 6.4 项目整体完成率

项目整体完成率采用五类指标等权平均：

`Overall = round((M + P + B + S + L) / 5)`

按照 Demo 初始数据：`M=100`、`P=66`、`B=99`、`S=75`、`L=57`，因此项目整体完成率为 `79%`。

## 6.5 最近 7 天更新

- 统计对象范围为五类业务对象。
- 统计键为对象内部主键与业务类型组合。
- 每个对象仅保存并展示当前最后更新时间，因此统计窗口内同一对象天然只计一次。
- 新增和编辑均更新最后更新时间；删除后对象不再参与统计。
- 列表按最后更新时间倒序排列。

## 6.6 实际完成与进度联动

对钢管桩、主体构件、附属构件和总装任务执行以下双向一致性约束：

1. 填写实际完成日期后，系统立即将进度自动设为 100%，状态设为“已完成”。
2. 进度填写为 100% 时，实际完成日期必填；缺失时禁止保存并提示“请选择实际完成”。
3. 已存在实际完成日期时，不允许把进度改为 100% 以下；用户应先清除实际完成日期。
4. 清除实际完成日期时不自动降低进度；若进度仍为 100%，保存时继续要求填写实际完成日期。
5. 实际完成日期不得早于实际开始日期。

备料没有独立进度输入，使用以下等价联动：

1. 填写实际末日到货后，系统自动将已到货量设为计划量，使备料进度变为 100%、状态变为“已完成”。
2. 已到货量等于计划量、备料进度为 100% 时，实际末日到货必填；缺失时禁止保存。
3. 已存在实际末日到货时，不允许降低已到货量或提高计划量而使进度低于 100%；用户应先清除实际末日到货。
4. 清除实际末日到货但已到货量仍等于计划量时，保存仍因 100% 缺少实际末日到货而失败；用户需同步调整数量或重新填写日期。

## 6.7 日期规则

- 计划开始必须早于或等于计划完成。
- 实际完成存在时，实际开始必须存在。
- 实际开始必须早于或等于实际完成。
- 计划日期与实际日期之间不做先后限制。
- 系统不计算计划偏差、逾期状态或里程碑节点。

## 6.8 序号规则

- 序号是展示字段，不是内部主键。
- 序号按当前查询结果的当前顺序从 1 连续生成，不允许缺号。
- 分页时使用全量查询结果的连续序号：第 `n` 页首行序号为 `(n-1) × pageSize + 1`。
- 查询条件改变、对象新增、软删除或列表顺序改变后，序号立即重新计算。
- 新增对象默认追加至当前分类数据末尾。
- 页面当前不提供主动排序能力；若未来由平台提供排序，序号随排序结果变化。

## 6.9 最后更新时间

- 新增或编辑成功时，由服务端使用平台业务时区写入当前时间。
- 页面统一显示至分钟，格式为 `YYYY-MM-DD HH:mm`。
- 查看和查询不修改最后更新时间。
- 仅修改后成功保存才算一次更新；打开编辑弹窗但未保存不计更新。

## 6.10 软删除（逻辑删除）

- 删除成功后，数据记录继续保留在持久化存储中，并被标记为已删除。
- 业务列表、查询、分页、最近更新和总览指标仅使用未删除记录。
- 本页面不提供回收站或恢复入口；恢复机制不属于本页面能力。
- 删除必须经过二次确认。
- 删除后所有受影响的列表数量、序号、分页和总览指标实时重算。

# 7. 交互与状态设计

## 7.1 弹窗模式

| 模式 | 字段状态 | 底部按钮 |
|---|---|---|
| 新增 | 可编辑字段为空或使用默认值；系统字段只读 | 取消、保存 |
| 查看 | 所有字段只读/禁用 | 关闭 |
| 编辑 | 可编辑字段回填；系统字段只读 | 取消、保存 |

弹窗标题使用“新增/查看/编辑 + 对象类型”，查看和编辑既有对象时追加对象名称或编号。

## 7.2 校验反馈

- 字段级错误展示在对应控件下方，不使用仅顶部汇总的方式替代。
- 一次保存应展示本次可识别的全部字段错误。
- 用户修正后再次保存，已修正字段的错误提示清除。
- 存在错误时不关闭弹窗、不写入数据、不刷新最后更新时间。

## 7.3 自动联动

- 修改备料计划量或已到货量时，状态实时更新。
- 修改普通进度时，状态实时更新。
- 填写实际完成日期时，进度和状态实时更新为 100%/已完成。
- 自动更新的只读字段不将弹窗误判为用户主动修改之外的第二次修改。

## 7.4 删除确认文案

确认提示格式：`确认删除{对象类型}「{对象名称或编号}」？删除后该对象将从业务列表和统计中移除。`

## 7.5 未保存修改确认

触发条件为任一可编辑字段的当前值与弹窗打开时初始值不同。确认弹窗至少提供“继续编辑”和“放弃修改”两个明确操作。

## 7.6 空值和空结果

- 表格无匹配数据：展示“暂无符合条件的数据”。
- 可选日期、备注和设备为空：列表展示“—”。
- 最近 7 天无更新：展示“最近7天暂无更新数据”。
- 分类无数据时，其指标按 0 计算。

# 8. 非功能需求

## 8.1 一致性

- 新增、编辑、删除成功后，列表、分页和总览必须基于同一份已提交数据刷新。
- 同一对象不得因快速重复点击保存而产生重复记录。
- 总览指标计算使用服务端或统一业务逻辑，不允许各页面分别实现不同口径。

## 8.2 安全与权限

- 身份认证、菜单访问、操作授权和数据范围继承现有平台 RBAC。
- 本模块不得绕过平台鉴权直接执行新增、编辑或删除。
- 本 PRD 不新增模块角色、字段级权限或独立账户体系。

## 8.3 兼容性与可用性

- 浏览器兼容范围、字体、日期控件和人员字典控件遵循现有平台标准。
- 所有可操作控件应有明确的可用、禁用和错误状态。
- 横向滚动时固定列应持续显示对象定位信息。

## 8.4 时间与数据格式

- 业务日期不含时分秒。
- 最后更新时间按平台业务时区记录，并显示至分钟。
- 数值计算不得受浏览器语言、小数点格式或客户端时区差异影响。
